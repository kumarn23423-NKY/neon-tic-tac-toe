# 🎮 Neon Tic Tac Toe
An attractive neon-themed Tic Tac Toe game built using HTML, CSS, and JavaScript.

### Features
- Two-player mode
- Play against the computer
- Score tracking
- Winning combinations and draw detection
- Responsive neon UI

### Technologies
HTML5 | CSS3 | JavaScript

### How to Run
Open `index.html` in any modern web browser.
